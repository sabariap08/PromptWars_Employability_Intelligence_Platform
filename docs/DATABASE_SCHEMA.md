# Database schema

MongoDB (Atlas) or mongomock in demo mode. Documents use string UUID `_id` values generated by the application, and UTC datetimes serialized as ISO strings by the JSON provider. No referential integrity is enforced by the database; services enforce ownership and tenant rules.

## Collections

### Identity and tenancy

#### `users`

| Field | Type | Notes |
| --- | --- | --- |
| `_id` | string | UUID |
| `full_name`, `email` | string | `email` normalized lowercase and unique |
| `password_hash` | string | bcrypt hash; never serialized |
| `role` | string | `SUPER_ADMIN`, `UNIVERSITY_ADMIN`, `ORGANIZATION_ADMIN`, `STUDENT`, `EMPLOYEE` |
| `organization_id` | string \| null | Null only for Super Admin |
| `department_id` | string \| null | Must belong to the same organization |
| `phone`, `designation` | string | |
| `account_status` | string | `EMAIL_VERIFICATION_PENDING`, `PENDING_APPROVAL`, `APPROVED`, `REJECTED`, `SUSPENDED`, `INACTIVE` |
| `email_verified` | bool | Required for login |
| `email_verification_token` | string \| null | SHA-256 hash of the raw token |
| `email_verification_expires_at` | datetime | 48 hours |
| `is_expert` | bool | Enables expert review for employees |
| `approved_at`, `approved_by`, `rejection_reason` | mixed | Audit trail |
| `created_at`, `updated_at` | datetime | |

Indexes: unique `email`; `(organization_id, role, account_status)`; `email_verification_token`.

#### `organizations`

`name`, `organization_type` (`UNIVERSITY`/`COMPANY`), `subtype`, `industry`, `location {country, state, district, city}`, `official_email`, `website`, `contact_number`, `address`, `registration_identifier`, `verification_documents`, `approval_status`, `rejection_reason`, `approved_at`, `approved_by`, timestamps.

Indexes: `name`, `official_email`, `registration_identifier`, `(organization_type, approval_status)`.

#### `departments`

`organization_id`, `name`, `code`, timestamps. Index: `(organization_id, name)`.

#### `approval_requests`

`request_type` (`ORGANIZATION`/`MEMBERSHIP`), `applicant_user_id`, `organization_id`, `requested_role`, `assigned_approver_role`, `status` (`PENDING`/`APPROVED`/`REJECTED`), `reviewed_by`, `rejection_reason`, timestamps.

### Learner evidence

#### `learner_profiles`

One per learner (`user_id` unique). `organization_id`, `learner_type` (`STUDENT`/`EMPLOYEE`), `education {degree, academic_year, year_of_study, roll_number, department_name}`, `employment {designation, employment_type, years_experience, department_name}`, `soft_skills[]`, `interests[]`, `target_career_id`, `learning_style`, `weekly_hours`, `onboarding_complete`, timestamps.

#### `learner_skills`

`user_id`, `organization_id`, `skill_name`, `skill_id`, `self_level`, `proficiency` (0–100), `target_proficiency`, `confidence` (`LOW`/`MEDIUM`/`HIGH`), `verification_status` (`SELF_REPORTED`/`PARTIALLY_VERIFIED`/`VERIFIED`), `evidence_count`, `breakdown[]`, `history[]`, `last_assessed_at`, timestamps.

Unique index: `(user_id, skill_name)`. Index: `(organization_id, skill_name)`.

#### `skill_evidence`

`user_id`, `organization_id`, `skill_name`, `source_type` (`ASSESSMENT`/`CERTIFICATION`/`PROJECT`/`TRAINER`/...), `source_id`, `title`, `score`, `verified`, `notes`, `created_at`.

#### `certifications`

`user_id`, `organization_id`, `name`, `issuer`, `issued_on`, `skills[]`, `status` (`PENDING_VERIFICATION`/`VERIFIED`/...), `file_path`, `assessment_id`, timestamps.

#### `projects`

`user_id`, `organization_id`, `name`, `description`, `technologies[]`, `repo_url`, `skills[]`, `ai_analysis {follow_up_assessment_id, ...}`, timestamps.

### Catalog

#### `skills`

`name` (unique), `category`, `description`, `created_at`.

#### `career_roles`

`name`, `description`, `experience_level`, `required_skills [{skill_id, skill_name, min_proficiency, weight}]`, `preferred_skills [...]`, `certifications[]`, `project_expectations`, `milestones[]`, `is_active`, timestamps.

#### `learning_resources`

`title`, `provider`, `url`, `resource_type`, `skill_names[]`, `difficulty`, `duration_hours`, `description`, `is_trusted`, `created_by`, `created_at`.

#### `assessment_questions`

`skill_name`, `difficulty` (`EASY`/`MEDIUM`/`HARD`), `question_type` (`FACTUAL`/`SCENARIO`/`PRACTICAL_WRITTEN`), `prompt`, `options[]`, `correct_option` (letter `A`–`F`), `correct_keywords[]`, `explanation`, `points`, `created_at`.

### Assessments

#### `assessments`

A prepared assessment definition bound to one learner: `user_id`, `organization_id`, `purpose` (`BASELINE`/`SKILL_CHECK`/`CERTIFICATION`/`PROJECT`), `title`, `skill_names[]`, `question_ids[]`, `time_limit_seconds`, `related_id`, `status`, `created_at`.

#### `assessment_attempts`

`user_id`, `organization_id`, `assessment_id`, `purpose`, `title`, `status` (`IN_PROGRESS`/`SUBMITTED`/`EVALUATED`), `attempt_number`, `questions[]` (snapshot with shuffled options), `answer_key`, `started_at`, `expires_at`, `submitted_at`, `evaluated_at`, `answers[{question_id, selected_option, text_answer}]`, `question_breakdown[]`, `score`, `topic_scores{}`, `integrity {tab_switch_count, visibility_events, client_events[], flags[], risk_level, note}`, `summary`, `created_at`.

#### `assessment_integrity_events`

`attempt_id`, `user_id`, `event_type`, `detail`, `at`.

### Learning and progress

#### `learning_roadmaps`

`user_id`, `organization_id`, `career_role_id`, `career_name`, `version`, `status` (`ACTIVE`/`ARCHIVED`), `trigger`, `rationale`, `readiness_snapshot`, `phases [{phase_number, title, objective, tasks[]}]`, `estimated_hours`, timestamps.

Task objects inside phases: `id`, `resource_title`, `skill_name`, `est_hours`, `difficulty`, `status` (`PENDING`/`IN_PROGRESS`/`COMPLETED`), `exercise`, `checkpoint`, `resource_url`, `resource_type`, `provider`, `phase_title`, `remediation`, `added_reason`.

#### `learning_activity`

`user_id`, `organization_id`, `roadmap_id`, `task_id`, `task_title`, `skill_name`, `activity_type`, `status`, `self_reported`, `evidence_url`, `hours`, `created_at`, `completed_at`.

#### `progress_records`

One per user (unique `user_id`): `career_readiness`, `roadmap_completion`, `skills_verified`, `assessments_taken`, `average_score`, `history[]` (last 60 snapshots), timestamps.

#### `mentor_conversations`

One per user (unique `user_id`): `messages [{role, content, provider, created_at}]`, `suggestions[]`, timestamps.

### Operations

#### `notifications`

`user_id`, `organization_id`, `title`, `message`, `type` (`INFO`/`SUCCESS`/`WARNING`/`APPROVAL`), `link`, `read` (bool), `created_at`. Index: `(user_id, read)`.

#### `audit_logs`

`actor_id`, `actor_role`, `organization_id`, `action`, `target_type`, `target_id`, `detail`, `ip`, `created_at`.

#### `ai_agent_executions`

`workflow`, `agent_name`, `event`, `status` (`SUCCESS`/`FAILED`), `provider`, `model`, `user_id`, `organization_id`, `input_summary`, `output_summary`, `duration_ms`, `error`, `handoff_to`, `created_at`. Index: `created_at`.

#### `ai_provider_settings`

Single document `_id: "global"`: `primary_provider`, `fallback_order` (comma-separated), `updated_at`.

#### `trainer_assignments`

`trainer_id`, `learner_id`, `organization_id`, `created_by`, `created_at`. Index: `(trainer_id, learner_id)`. The presence of a record authorizes expert review, including cross-organization.

#### `trainer_feedback`

`trainer_id`, `learner_id`, `organization_id`, `skill_name`, `rating` (1–5), `feedback`, `created_at`. Ratings ≥ 3 create verified evidence.

## Lifecycle summary

1. Registration creates `users`, `learner_profiles`, `approval_requests` and (for institutions) `organizations`.
2. Email verification flips `email_verified` and moves learners to `PENDING_APPROVAL`.
3. Approval flips `account_status` to `APPROVED` and resolves the request.
4. Profile and evidence updates upsert `learner_skills` and append `skill_evidence`.
5. Assessments clone question snapshots into attempts; evaluation writes scores, topic scores and integrity flags.
6. Roadmap generation archives the active plan and inserts a new version.
7. Every significant action can append `audit_logs`, `notifications` and `ai_agent_executions`.
